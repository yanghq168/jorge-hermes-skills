## 脚本文件构成（v1.2.0）

| 文件 | 作用 |
|---|---|
| `toutiao-article-daily.py` | 主脚本：模板、发送、投递、轮换逻辑 |
| `toutiao_topics_extra.py` | 扩库：`EXTRA_TOPICS`（4条长文）、`EXTRA_MICRO_TOPICS`（4条微头条） |

## 微头条模块（v1.1.0新增）

独立于长文的微头条，每天生成2条：
- 字数：150-250字
- 选题：来自 `MICRO_TOPICS_POOL`（v1.2.0 共 **10** 个独立选题，跨天 LRU 去重）
- 结构：方向 → 标题 → 内容 → 对话高亮 → 配图提示词 → 标签
- 邮件格式：追加在长文HTML下方，用深蓝分隔线区分

## 核心数据结构

```python
topic = {
    "direction": "遗产分配",           # 选题方向
    "category": "情感·家庭婚姻",       # 头条类目
    "title": "72岁老人存了40万...",    # 文章标题（需含具体年龄/数字）
    "hook": "这是网友@老陈头 的投稿...",  # 钩子（需含真实感细节）
    "story_a": "...",                 # 故事A（负面/反例）
    "story_a_dialogue": "...",        # 故事A对话高亮
    "story_a_ending": "...",          # 故事A结尾
    "story_b": "...",                 # 故事B（正面/智慧案例）
    "story_b_ending": "...",          # 故事B结尾
    "viewpoint": "...",               # 反共识犀利观点
    "action": "...",                  # 给读者的行动台阶
    "golden1": "...",                 # 金句1（故事A结尾）
    "golden2": "...",                 # 金句2（故事B结尾）
    "golden3": "...",                 # 金句3（文章结尾）
    "tags": ["遗产分配", "遗嘱", ...], # 话题标签
    "cover_prompt": "... --ar 16:9 --v 6",  # 封面图DALL-E提示词
    "in_image_prompts": [             # 5张文中配图
        {"num": 1, "scene": "场景名", "desc": "描述", "prompt": "DALL-E提示词"},
        {"num": 2, "scene": "...", "desc": "...", "prompt": "..."},
        ...
    ],
}
```

### 钩子真实感要求（头条特色）
头条钩子不能是干巴巴一句话，必须包含：
- 具体时间："有一天晚上"、"那天凌晨"
- 具体地点："我家楼下那个菜市场"、"医院走廊里"
- 具体数字："38度5"、"15平米的出租屋"
- 具体对话：要有引号内的原话，不是"他说"

示例：
```
# ❌ 旧版（干巴巴）
"这是读者@老王 的真实经历，看完我心里很不是滋味。"

# ✅ v1.1.0（真实感细节）
"这是读者@老王 的投稿，讲的是他自己的故事。他说有一天他发烧，躺了一天，没人知道。晚上量体温，38度5，他给自己倒了一杯水，就这么睡着了。"
```

## 关键实现细节

1. **深蓝Banner**：`#1a2a4a → #162340 → #0f1a30` 渐变，稳重深沉
2. **金句高亮**：红色 `#c0392b`，对比公众号版更浓烈
3. **话题标签**：蓝色 `#2980b9`，与深蓝Banner呼应
4. **互动问题**：争议性，让两拨人想转发讨论
5. **配图提示词**：纪录片风格，情绪张力，无文字，16:9横版，--ar 16:9 --v 6
6. **钩子真实感**：头条钩子需包含具体时间、地点、数字、对话细节

## 头条发布检查清单（v1.2.0）

> ⚠️ **清单里的数字必须被自动断言**。v1.1.0 的清单写着「1500字以上」，
> 但实测每篇只有 813-1159 字，**没有一篇达标** —— 清单是愿望，从来没人量过。
> 下面的「自动校验」列标出哪些项应该由脚本自己断言。

- [ ] 发件人是否为「围炉家常话（头条）」？
- [ ] 钩子有没有真实感细节？（时间/地点/数字/对话）
- [ ] 长文配图够不够5张？（封面1张+文中5张=6张）— **自动校验**
- [ ] 微头条是否2条独立选题？（150-250字/条）— **自动校验**
- [ ] 同日2条微头条方向是否不同？— **自动校验**
- [ ] 字数够不够？（1500字以上，长文吃流量）— **自动校验**（正文≥1100 + 钩子/观点/行动）
- [ ] 故事够不够完整？（两个完整故事 + 对话 + 结局）— **自动校验**（grep `故事A·对话`/`故事A·结局`/`故事B·结局`）
- [ ] 观点够不够犀利？（挑战传统观念，反共识）
- [ ] 有没有具体数字？（存款、房产、退休金金额）
- [ ] 有没有对话或心理描写？
- [ ] 配图提示词有没有「无文字/no text」？
- [ ] 互动问题是不是争议性的？
- [ ] **本次选题是否是最近 10 天内没出现过的？** — **自动校验**（LRU 轮换）
- [ ] **模板占位符 ↔ kwargs 是否一一对应？** — **自动校验**（防 `str.format()` 静默丢弃）
